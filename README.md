# 法条分镜工作台

人工智能课程作业。输入一条法条，查看主体、条件、行为、规范性质及理由，再把每个镜头的提示词复制给视频生成工具。页面提供原文、理论卡出处、分镜旁白与完整 JSON 下载。

## 给第一次用的同学

配置模型并打开网页后，默认就是“对话”。第一条直接粘贴完整法条。等分析和分镜出来，再问“第二段为什么属于应为模式？”或“把第二个镜头换成校园场景，保留旁白”。改好的分镜会同步到页面和下载文件。换另一条法条，先点“新对话”。对话保存在当前网页会话中，最近六轮和当前作品用于后续问答。

**手里的资料怎么用？** 假如你负责论文，先从一页里挑出能解释“应当”的一段，记下页码，再照 materials/theory.json 的格式填一张卡。假如你负责视频，挑一个镜头，用三句话写清“画面是什么、旁白说什么、它解释哪个知识点”，放进 materials/shots.md。到页面展开“课程框架与参考资料”，传入整理好的文件，接着发法条即可。

默认按讨论稿里的假定条件、行为模式、法律关系和法律后果分析，按约 40 秒警示短片设计镜头、旁白、字幕和音轨。组员应对照原文审核后再制作成片。

## 第一次运行

安装 Python 3.10 或更新版本，解压项目，在有 app.py 的目录打开终端。

**Windows PowerShell**

```powershell
py -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m streamlit run app.py
```

**macOS / Linux**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

打开终端显示的本地地址（通常为 http://localhost:8501）。选“离线示例”并点“查看示例”。这是预写的借书案例，首次安装依赖后，演示无需联网或密钥。

## 分析自己的法条

使用支持 OpenAI 格式 chat/completions 的服务。退出正在运行的服务（Ctrl+C），先在同一个终端设置以下变量，再执行上面的 streamlit 启动命令。

| 变量 | 填什么 |
| --- | --- |
| LAW_API_BASE | 服务商提供的 API 根地址，通常以 /v1 结尾。默认 https://api.openai.com/v1 |
| LAW_MODEL | 账号可调用的模型 ID |
| LAW_API_KEY | 服务商签发的密钥，仅设置在本机 |

PowerShell 使用 `$env:LAW_MODEL="你的模型ID"`，bash 使用 `export LAW_MODEL="你的模型ID"`。另两个变量按相同方式设置。请勿把真实密钥写入提交文件。

1. 选“AI 生成”，粘贴一条完整法条，保留条件和例外。
2. 展开“课程框架与参考资料”，按老师要求填分类维度。可上传整理好的卡片和分镜示例。
3. 点“分析并生成分镜”。程序先按关键词匹配理论卡，选出最多六张，再调用模型两次，先分析再生成镜头。输入原文、课程框架、命中摘录和分镜示例会按阶段发给配置的模型服务。
4. 展开分析项核对原句与出处，再按镜头的分析编号核查旁白。点击提示词代码框的复制按钮，粘贴到视频工具。需要交作业时下载 JSON。修改输入后需再次点生成，结果区显示上次生成时的原文。

## 组员怎么准备材料

**收论文的同学**：参考 materials/theory.json。每张卡只放一个观点，source 填作者、题名、年份和页码；text 放核对过的摘录；keywords 填法条中可能出现的触发词。比如“未经”“除外”可以作为例外条件卡的关键词。上传时提供完整 JSON 数组，内容替换内置卡。内置三张卡是自编教学材料。PDF 需要先摘录，扫描件可先 OCR 再校对。

**收视频的同学**：参考 materials/shots.md，每个片段写下时间、画面、旁白和表达目的，保存为 UTF-8 的 .md 或 .txt。保留视频出处供组内核查。上传整理后的分镜表即可。

**负责验收的同学**：选一条老师讲过的法条，先独立写下标准分析，再核对系统有没有遗漏例外、误判性质或编造处罚。没有命中卡片的分类会标“待核对”。关键词检索可能漏掉同义表述，发现漏检时补关键词。程序校验原文是否逐字出现、资料编号是否有效、镜头是否覆盖各分析项；理论适用性仍由组员判断。

## 常见问题

- HTTP 401/403：检查密钥及模型权限。HTTP 404：检查根地址和模型 ID。HTTP 429：查看额度、并发限制，稍后重试。
- 返回格式错误：换用能稳定输出 JSON 的对话模型，或缩短输入重试。任一阶段失败都可以重新生成，会重新调用模型。
- 页面没有自动打开：复制终端里的 Local URL 到浏览器。关闭终端会停止应用。
